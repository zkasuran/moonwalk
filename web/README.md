# MoonWalk web demo

A self-contained page that reads the live MoonWalk channel on Arc mainnet (chain
5042) straight from the public RPC in the browser. No wallet, no funds, no
backend. It shows the channel state, the per-person on-chain caps and the proof
run, all read live.

`index.html` is the whole app. It is also served as the site landing page at
`docs/index.html`. Open it directly or host it on any static host. The richer
project overview is `docs/overview.html`.
